# Tool categories

## Technical SEO

Redirect Lab, Crawler Access Matrix, Hreflang Auditor, Structured Data Graph, Canonical Guard, Sitemap Doctor, and search readiness scoring.

## GEO

Entity identity, AI crawler access, source support, freshness, sameAs, authorship, machine-readable page identity, and optional llms.txt diagnostics.

## AEO

Question headings, answer blocks, lists and tables, FAQ/QAPage schema, speakable markup, authorship, source support, and answer-source eligibility.

## Indexing operations

IndexNow key validation, sitemap parsing, deduplication, batching, dry runs, and submission.

## Graphical frontend boundaries

GitHub Pages is static. It can build commands, explain matrices, visualize local JSON reports, and inspect pasted evidence. It cannot reliably fetch arbitrary third-party websites because browser cross-origin policy is controlled by the audited website.
