# Changelog

## 1.0.0 - 2026-07-29

- Initial public release.
- Added PowerShell, Python, macOS, and Linux entry points.
- Added recursive sitemap-index and GZip sitemap support.
- Added canonical-host, key-scope, duplicate, and URL validation.
- Added exact alternate-host rewriting and dry-run mode.
- Added automatic batching at the IndexNow 10,000-URL limit.
