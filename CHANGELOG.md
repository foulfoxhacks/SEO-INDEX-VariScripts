# Changelog

## 1.1.0 - 2026-07-29

### Added

- Unified `seo-index` cross-platform terminal toolkit
- Semi-graphical interactive menu with ANSI scorecards and progress bars
- Animated fox-tail splash branded `foulfoxhacks • aka The Dev Sammy`
- Google, Bing, and general index-readiness scoring profiles
- Transparent weighted checks, verification coverage, and critical-failure caps
- Canonical Guard for sitemap-wide redirect, host, and canonical audits
- Sitemap Doctor for XML errors, sitemap indexes, GZip, duplicate URLs, hosts, fragments, HTTPS, `lastmod`, redirects, and HTTP checks
- Page checks for robots.txt, robots meta, `X-Robots-Tag`, canonical, crawlable text, title, description, H1, viewport, and JSON-LD
- JSON and Markdown report exports
- Unified IndexNow launcher subcommand
- Windows PowerShell script endpoints for scoring, canonical checks, and sitemap checks
- Linux/macOS shell script endpoints
- Windows `irm ... | iex` installer and macOS/Linux `curl ... | sh` installer
- Standard-library unit test suite with a local fixture server

### Preserved

- Original public PowerShell, Python, macOS, and Linux IndexNow runners
- Recursive sitemap-index and GZip sitemap support
- Canonical-host and key-scope validation
- Duplicate removal, dry-run mode, and 10,000 URL batching

## 1.0.0 - 2026-07-29

- Initial public IndexNow runner release.
